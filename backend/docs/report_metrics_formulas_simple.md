# 回测报告统计指标计算公式说明

本文档说明回测报告右侧“统计指标”中各项数值的计算口径。

## 基础定义

每一笔已平仓交易都有一个盈亏值：

```text
pnl = 该笔交易盈亏
```

按盈亏把交易分为三类：

```text
盈利单：pnl > 0
亏损单：pnl < 0
持平单：pnl = 0
```

当前代码中，部分统计会把 `pnl = 0` 的持平单计入“亏损侧”，即使用：

```text
亏损/持平单：pnl <= 0
```

## 盈亏汇总

| 指标 | 计算公式 | 说明 |
| --- | --- | --- |
| 净利润 | 所有交易 pnl 之和 | 总盈利和总亏损相加后的结果 |
| 总盈利 | 所有盈利单 pnl 之和 | 只统计 `pnl > 0` 的交易 |
| 总亏损 | 所有亏损/持平单 pnl 之和 | 当前代码为负数口径，统计 `pnl <= 0` |
| 总盈利/总亏损 | 总盈利 / abs(总亏损) | 总亏损为 0 时返回 0 |

## 交易笔数

| 指标 | 计算公式 | 说明 |
| --- | --- | --- |
| 交易手数 | 交易总笔数 | 已平仓交易数量 |
| 盈利比率 | 总盈利 / abs(总亏损) | 当前代码口径不是胜率，而是盈亏比 |
| 盈利手数 | 盈利单数量 | `pnl > 0` 的数量 |
| 亏损手数 | 亏损/持平单数量 | 当前代码统计 `pnl <= 0` |
| 持平手数 | 持平单数量 | `pnl = 0` 的数量；部分代码版本固定为 0 |

## 平均盈亏

| 指标 | 计算公式 | 说明 |
| --- | --- | --- |
| 平均利润 | 净利润 / 交易手数 | 没有交易时返回 0 |
| 平均盈利 | 总盈利 / 盈利手数 | 没有盈利单时返回 0 |
| 平均亏损 | 总亏损 / 亏损手数 | 通常为负数；没有亏损单时返回 0 |
| 平均盈利/平均亏损 | 平均盈利 / abs(平均亏损) | 平均亏损为 0 时返回 0 |

## 最大单笔盈亏

| 指标 | 计算公式 | 说明 |
| --- | --- | --- |
| 最大盈利 | 所有交易 pnl 的最大值 | 单笔最大盈利 |
| 最大亏损 | 所有交易 pnl 的最小值 | 单笔最大亏损，通常为负数 |
| 最大盈利/总盈利 | 最大盈利 / 总盈利 | 总盈利为 0 时返回 0 |
| 最大亏损/总亏损 | 最大亏损 / 总亏损 | 两者通常都为负数，结果通常为正 |
| 净利润/最大亏损 | 净利润 / 最大亏损 | 当前代码直接除以负数最大亏损，盈利时结果可能为负 |

## 连续盈亏

| 指标 | 计算公式 | 说明 |
| --- | --- | --- |
| 最大连续盈利手数 | 连续 `pnl > 0` 的最大笔数 | 遇到亏损/持平单会中断 |
| 最大连续亏损手数 | 连续 `pnl <= 0` 的最大笔数 | 当前代码把持平单计入亏损连续段 |

## 持仓周期

每笔交易先计算持仓周期：

```text
持仓周期 = (平仓时间 - 开仓时间) / 当前周期长度
```

例如：

```text
M30 周期下，持仓 90 分钟，则持仓周期 = 90 / 30 = 3
```

| 指标 | 计算公式 | 说明 |
| --- | --- | --- |
| 平均持仓周期 | 所有交易持仓周期之和 / 交易手数 | 没有交易时返回 0 |
| 平均盈利周期 | 盈利单持仓周期之和 / 盈利手数 | 没有盈利单时返回 0 |
| 平均亏损周期 | 亏损/持平单持仓周期之和 / 亏损手数 | 没有亏损单时返回 0 |
| 平均持平周期 | 持平单持仓周期之和 / 持平手数 | 没有持平单时返回 0 |

## 资金和成本

| 指标 | 计算公式 | 说明 |
| --- | --- | --- |
| 最大使用资金 | 回测过程中记录到的最大账户权益 | 来自 `max_equity` |
| 最大持仓手数 | 回测过程中记录到的最大持仓数量 | 来自 `max_position_size` |
| 交易成本合计 | 手续费 + 滑点 | 当前主要统计 `commission`，滑点多数情况下为 0 |

## 收益类

| 指标 | 计算公式 | 说明 |
| --- | --- | --- |
| 收益率 | 净利润 / 最大使用资金 | 最大使用资金为 0 时返回 0 |
| 年化收益率 | 当前代码固定为 0 | 暂未实现 |
| 有效收益率 | 当前代码固定为 0 | 暂未实现 |
| 月度平均盈利 | 当前代码固定为 0 | 暂未实现 |

## 注意事项

1. 当前代码里的“总亏损”“平均亏损”“最大亏损”通常是负数。
2. 当前代码里的“盈利比率”不是胜率，而是 `总盈利 / abs(总亏损)`。
3. 当前代码把 `pnl = 0` 的持平单计入亏损侧。
4. `净利润/最大亏损` 因为最大亏损是负数，所以净利润为正时结果可能是负数。
5. 部分代码版本里“平均盈利周期”“平均亏损周期”可能实际返回的是周期总和，不是真正平均值，需要以具体接口返回为准。
